Privacy Policy

Last updated: August 2, 2026 · Applies to Rider Wave (Android), beta/testing version

Plain-language summary: Rider Wave does not have a server or account system today. Everything the app records about you — your rides, routes, hazard reports, and posts — stays on your phone. Nothing is uploaded to us, because there is currently nowhere for it to go.

1. What this app is, today

Rider Wave is currently a beta/testing-stage, local-first motorcycle navigation and ride-tracking app. As of this policy's last update, Rider Wave has no backend server, no user accounts, and no sign-in. All app data is generated and stored directly on your device.

2. Data stored on your device

The app stores the following locally, using standard Android app-private storage (and, for one item noted below, Android's encrypted secure storage). None of it is transmitted to any Rider Wave-owned server, because none exists yet:

  • Profile information you enter (name, rider icon choice, bike/garage entries)
  • Saved routes and ride history (GPS tracks, distance, time, speed recorded during a ride)
  • Hazard reports and social posts ("waves") you create in the app
  • Favorite/saved places (home, work, recent searches)
  • App settings (map style, units, theme, developer/debug options)

You can permanently delete this data at any time from Settings → Your data in the app, or by uninstalling the app.

3. Location data

Rider Wave uses your device's GPS location, with your permission, to show your position on the map, provide turn-by-turn navigation, and record your ride track while the app is open. Location data is used entirely on-device for these purposes and is not uploaded to or stored on any Rider Wave server. The app currently requests location access only while it is in use (foreground) — it does not track your location in the background or while the screen is locked.

4. Optional OpenWeatherMap API key

If you choose to enter your own OpenWeatherMap API key in Settings for enhanced weather data, that key is stored using Android's encrypted secure storage (Android Keystore-backed), directly on your device. You control this key entirely — Rider Wave does not see, collect, or transmit it anywhere except directly to OpenWeatherMap's API when making the weather requests you've enabled.

5. Third-party services this app talks to

To provide maps, search, routing, and weather, Rider Wave sends necessary requests (such as your searched location or current position, when relevant to the feature) directly from your device to these independent, third-party services. Rider Wave does not operate any of them, and does not see or store the responses beyond normal on-device app use. Each is governed by its own separate privacy policy:

  • Nominatim / OpenStreetMap — address search and geocoding
  • Valhalla and OSRM — route calculation
  • Overpass API (OpenStreetMap) — nearby points of interest (gas, businesses)
  • Open-Meteo, and OpenWeatherMap if you supply a key — weather data
  • RainViewer — radar imagery overlay
  • Map tile providers (including OpenStreetMap-based and Esri sources) — the map imagery itself

We recommend reviewing each provider's own policy if you have questions about how they individually handle request data (such as IP address, which is inherent to any network request).

6. Music control bar

If you grant Notification Access, Rider Wave can display and control whatever music app you're currently playing (song title, artist, album art, play/pause/skip). This works by reading the Android system's local media session on your device — it never reads notification content, never requires logging into any music service, and this data never leaves your device.

7. No accounts, no analytics, no advertising

Rider Wave does not currently have user accounts, sign-in, or any cloud-based social features. The app does not integrate any analytics, crash-reporting, or advertising SDKs as of this policy's last update.

8. Children's privacy

Rider Wave is not directed at children, and we do not knowingly collect personal information from children. Since the app has no accounts or data submission to any server, there is no mechanism today for personal information to reach us from any user.

9. This is a beta app, and this policy will change

Rider Wave is under active development. Planned future features — such as a shared backend, user accounts, or business/social features — do not exist yet and are not described here as current fact. When any feature is introduced that changes how data is collected, stored, or transmitted, this policy will be updated first, and the "Last updated" date above will reflect that change.
